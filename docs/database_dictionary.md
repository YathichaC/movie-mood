# Database Dictionary

This dictionary describes the **8 JPA entity tables** in the **Movie Mood** project (Spring Boot / PostgreSQL), based on `movie-mood-develop.zip`.

## Conventions

**ID strategy**
- `UUID` — used for `User`, `Playlist`, `PlaylistDetail`, `Movielist`, `WatchHistory`, `UserDislikedGenre`, and `PasswordResetToken`.
- `String` — used for `Genre.genre_id`, representing an external genre identifier.
- `@GeneratedValue(strategy = GenerationType.UUID)` — used by `Playlist`, `WatchHistory`, and `UserDislikedGenre`; `Movielist` uses `@GeneratedValue` with `@UuidGenerator`.
- `UUID.randomUUID()` — called in Java constructors for `User` and `PasswordResetToken`; **not** a database `DEFAULT`.

**Constraints and audit strategy**
- `PK` = JPA primary key; `FK` = relationship mapped with `@JoinColumn`; `UQ` = JPA unique constraint; `NOT NULL` = explicitly set by `nullable = false` or primitive mapping.
- `Nullable by mapping` means no explicit `nullable = false` in the entity; it **does not prove** the database allows `NULL`.
- No shared `created_at` / `updated_at` audit fields are declared in these eight entities.
- No `ON DELETE CASCADE`, `SET NULL`, or `RESTRICT` database actions are confirmed. JPA `cascade` and `orphanRemoval` are not equivalent to database `ON DELETE` rules.

## Schema verification notes

- The project configures `org.postgresql.Driver` and `spring.jpa.hibernate.ddl-auto=validate`: Hibernate **validates**, rather than creates or updates, database tables.
- `spring.jpa.properties.hibernate.globally_quoted_identifiers=true` makes exact identifier spelling/case particularly important.
- The supplied ZIP contains no `.sql` migration/schema file. Thus `VARCHAR` lengths, DB-generated defaults, `ON DELETE` rules, and exact index definitions cannot be certified from this snapshot.
- The following query can be used against the actual database to verify column types and nullability:

```sql
SELECT table_name, column_name, data_type, character_maximum_length,
       is_nullable, column_default
FROM information_schema.columns
WHERE table_schema = 'public'
ORDER BY table_name, ordinal_position;
```
